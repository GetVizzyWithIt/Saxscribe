# Datasheet: technique and register sets

Short clips labelled by technique, register or instrument. Tier C.

| Set | Content | Labels | Licence | Folder |
| --- | --- | --- | --- | --- |
| SaxTimbre (Harvard Dataverse, doi:10.7910/DVN/WSFBIJ) | 191 tenor takes | Folder = technique: bisbigliando, flutter, growl, long vibrato, non-vibrato, multiphonics, quarter tones, slap, subtone | CC0 | `SaxTimbre/` |
| Vibrato Dataset (Zenodo 1016050) | 53 alto files | Vibrato presence and parameters | AGPL-3.0 per manifest (GPL per search notes); evaluation only | `VibratoDataset/` |
| Register Control in Saxophone Playing (Zenodo 22141453) | 280 files with mouth-pressure and lip-force sensors | Reviewed overtone/register labels | MIT | `SaxRegisterControl/` |
| Medley-solos-DB (Zenodo 3464194) | 477 three-second tenor clips | Instrument label only | CC BY 4.0 | `Medley-solos-DB/` |

## Uses
- Ground for articulation tags (growl, vibrato depth and rate, subtone, slap) and for altissimo/register checks.
- Medley-solos-DB: telling sax from other instruments, later.
- **Do not use for**: note segmentation scoring (no note labels).
