# Datasheet: MedleyDB-Pitch (pending access)

## Motivation
Subset of MedleyDB (Bittner et al., NYU, 2014) with human-checked pitch
lines for monophonic stems, for pitch-tracking research.

## Composition
Monophonic stems from multitrack recordings, including saxophone, each with a
human-checked f0. A separate open Zenodo record (4728793) holds 103 pYIN note
CSVs for these stems: machine-made, tier D.

## Uses
- **Role**: pitch-line check on real recordings; separation training (stems and mixes).
- **Do not use for**: grading notes against the pYIN note files.

## Distribution
Zenodo 2620624, on request (requested, pending). pYIN notes: Zenodo 4728793, CC BY 4.0 (downloaded).
